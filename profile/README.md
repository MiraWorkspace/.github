# Mira

本地优先的个人 AI 工作空间。

让 AI 在你的工作环境中协作，连接模型、工具与项目文件，
完成从任务执行到工作流自动化的日常工作。

[访问官网](https://miraworkspace.github.io/) ·
[下载安装](https://github.com/MiraWorkspace/Mira-Harness/releases) ·
[问题反馈](https://github.com/MiraWorkspace/Mira-Harness/issues)

## 我们正在构建

- **Mira / Harness**：面向桌面的 AI 工作空间，结合任务对话、项目文件、文档预览与工具执行。
- **工作流与自动化**：编排可重复执行的任务，保留运行记录和产物。
- **应用扩展与 SDK**：为独立子应用提供模型、存储、文件和隔离视图等宿主能力。
